# LeetCode Solutions & Review Notes

A collection of **Python** solutions to LeetCode problems, accompanied by structured review notes documenting problem-solving approaches, algorithmic analysis, and implementation improvements.

This repository focuses on developing a strong foundation in data structures and algorithms, writing efficient and maintainable code, and understanding the reasoning behind different solutions.

## Objectives

The goal is not simply to solve problems, but to develop a systematic approach to problem-solving and strengthen the technical skills required for software development.

- **Problem-solving:** Break down problem requirements, identify constraints and edge cases, and develop logical solutions.
- **Data structures and algorithms:** Select appropriate data structures and algorithms based on the characteristics of each problem.
- **Computational efficiency:** Analyse time and space complexity to evaluate performance and understand the trade-offs between different approaches.
- **Code quality:** Write clear, readable, and maintainable Python code.
- **Continuous improvement:** Compare alternative solutions, identify inefficiencies, and refine implementations where possible.

## Repository Structure

```text
leetcode/
├── solutions/    # Python implementations
├── notes/        # Structured review notes
└── README.md
```

- `solutions/` contains Python implementations of LeetCode problems.
- `notes/` contains corresponding review notes covering algorithmic approaches, complexity analysis, implementation details, and key insights.

Each problem has a corresponding solution and review note, keeping the implementation separate from the analysis while making both easy to revisit.

## Problem Analysis and Review

Solutions are reviewed with an emphasis on understanding the algorithm, evaluating its efficiency, and identifying opportunities for improvement.

Review notes document:

- **Approach:** The algorithmic strategy and the reasoning behind the chosen solution.
- **Implementation:** Important implementation details, including data structure choices and handling of edge cases.
- **Complexity analysis:** Time and space complexity, with an explanation of the factors that influence performance.
- **Insights:** Key observations, common pitfalls, and lessons that may be applied to similar problems.
- **Optimisation:** Alternative approaches and potential improvements when they offer meaningful insights.

The aim is to build not only the ability to solve individual problems, but also the ability to explain, evaluate, and improve solutions.

## Scope

The repository primarily focuses on algorithmic problem-solving in Python, with an emphasis on data structures, algorithm design, computational efficiency, and code quality.

As the collection grows, solutions and review notes will provide a reference for revisiting concepts, comparing approaches, and reinforcing problem-solving skills.
